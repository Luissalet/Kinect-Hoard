# Inventario de las muestras instaladas del Developer Toolkit 1.8

Se han inspeccionado los directorios de muestras C#, C++ y VB del Toolkit 1.8 instalado en este equipo. La tabla cuenta **56 directorios**: 31 C#, 20 C++ y 5 VB. Una variante en otro lenguaje no implica una función de hardware nueva. «Equivalente» significa que Hoard ofrece la capacidad indicada, no que ejecute el código del Toolkit. Véase [el estado comprobado con hardware](capabilities.json).

El [mapa de adaptación](toolkit-map.md) resume las funciones de Hoard. Este inventario conserva los nombres de los ejemplos para que un agente pueda localizar cada referencia sin interpretar una demo C++, C# y VB como tres capacidades distintas.
