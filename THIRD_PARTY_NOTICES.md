Su uso está sujeto a los [términos del SDK 2.0 de Microsoft](https://download.microsoft.com/download/0/D/C/0DC5308E-36A7-4DCD-B299-B01CDFC8E345/Kinect-SDK2.0-EULA_en-US.pdf). Microsoft conserva sus derechos sobre estos archivos.
- **OpenKinect/libfreenect** (`freenect.dll`): código publicado con elección entre Apache 2.0 y GPL 2.0. Esta distribución usa Apache 2.0; avisos en `licenses/libfreenect-APACHE20.txt` y `licenses/libfreenect-CONTRIB.txt`. Código fuente fijado y compilación reproducible en `build-native360.ps1`; proyecto: <https://github.com/OpenKinect/libfreenect>.
- **libusb 1.0.27** (`libusb-1.0.dll`): licencia LGPL 2.1, texto en `licenses/libusb-COPYING.txt`. Se enlaza como DLL separada y sustituible; el código fuente completo se incluye en `licenses/libusb-1.0.27-source.tar.bz2` (SHA-256 `FFAA41D741A8A3BEE244AC8E54A72EA05BF2879663C098C82FC5757853441575`). Origen: <https://github.com/libusb/libusb/releases/tag/v1.0.27>.

Kinect Hoard utiliza el runtime de Kinect para Windows 2.0 de Microsoft para acceder a la Kinect One. El instalador del runtime y el controlador USB se obtienen de Microsoft por separado y no se redistribuyen en este ZIP. Hoard solo guarda capturas en rutas locales elegidas por el usuario; no las transmite a terceros. Una malla facial puede identificar a una persona, por lo que debe obtenerse su consentimiento antes de guardarla o compartirla.
